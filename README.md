# pages-redirect

GitHub Pages for this repo is served from **this branch**, and it contains one
thing: a redirect from the old game URL to its new home.

- old: https://machangdoniel.github.io/volt-vs-titan/
- new: https://machangdoniel.github.io/game/volt-vs-titan/

Both games now live in the [`game`](https://github.com/MachangDoniel/game) repo,
which hosts https://machangdoniel.github.io/game/.

The VOLT vs TITAN source is still on `main` here. Note that the
`Deploy to GitHub Pages` workflow on `main` would switch Pages back to a
workflow build and overwrite this redirect, so don't run it.
